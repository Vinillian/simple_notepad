# Simple Notepad 📒

Простое веб-приложение для заметок и ссылок с двумя режимами отображения.  
Теперь с **собственным бэкендом на Node.js + Express**, базой данных **SQLite** и интерактивной документацией API через **Swagger**.

## ✨ Возможности

- **Заметки и ссылки** – автоматическое определение типа по содержимому.
- **Группы (категории)** – цветовая маркировка и фильтрация.
- **Два режима отображения**:
  - *Список* – компактный вид с favicon и доменом.
  - *Превью* – карточки с изображением, заголовком и описанием (метаданные загружаются через microlink.io).
- **Поиск** по заголовку, содержимому и метаданным ссылок.
- **Пагинация** – подгрузка по 20 элементов.
- **Экспорт/импорт** данных в JSON (локально, для резервного копирования).
- **Синхронизация с сервером** – данные хранятся в SQLite, доступны через REST API.
- **Интерактивная документация API** – Swagger UI по адресу `/api-docs`.

## 🛠️ Технологии

- **Фронтенд**: HTML5, CSS3, JavaScript (ES6+), Font Awesome, Intersection Observer.
- **Бэкенд**: Node.js, Express, SQLite3, CORS.
- **Документация**: Swagger (swagger-jsdoc + swagger-ui-express).

## 🚀 Быстрый старт

### 1. Клонирование репозитория
```bash
git clone https://github.com/Vinillian/simple_notepad.git
cd simple_notepad
```

### 2. Запуск бэкенда
```bash
cd backend
npm install          # установка зависимостей
npm install -g nodemon # (опционально) для автоматического перезапуска
npx nodemon server.js # или node server.js
```
Сервер запустится на `http://localhost:3000`.

### 3. Запуск фронтенда
Откройте файл `frontend/index.html` в браузере.  
**Важно:** для корректной работы API фронтенд должен быть открыт через локальный сервер (например, `npx live-server frontend`), иначе могут быть проблемы с CORS. Бэкенд уже настроен на приём запросов с любых источников.

## 📖 Как пользоваться

### Группы
- Введите название новой группы в поле «Новая группа...» и нажмите `+`.
- Кликните по группе в списке, чтобы отфильтровать заметки.
- Цвет группы выбирается автоматически.

### Добавление заметки/ссылки
1. Заполните поля:
   - **Название** (необязательно, если пусто – генерируется из содержимого)
   - **Группа** – выберите из выпадающего списка
   - **Текст** – если это ссылка, она должна начинаться с `http://` или `https://`
2. Нажмите «Сохранить заметку» или `Ctrl+Enter`.

Для ссылок автоматически загружаются метаданные (заголовок, описание, изображение) через [microlink.io](https://microlink.io).

### Режимы отображения
Кнопки «Список» / «Превью» в шапке или горячие клавиши `Ctrl+1` / `Ctrl+2`.

### Поиск
Начните вводить текст в поле поиска – результаты фильтруются по заголовку, содержимому и метаданным ссылок.

### Экспорт/импорт
- **Экспорт** – сохраняет все данные в JSON-файл (для резервного копирования).
- **Импорт** – загружает данные из JSON-файла (работает локально, не синхронизируется с сервером; для импорта в БД используйте скрипт `backend/scripts/importFromJson.js`).

### Управление заметками
- ✏️ – редактировать (через интерфейс)
- 🗑️ – удалить (с подтверждением)

## 📡 API и документация

После запуска бэкенда документация Swagger доступна по адресу:  
[http://localhost:3000/api-docs](http://localhost:3000/api-docs)

Там можно увидеть все эндпоинты, их параметры и даже отправлять запросы прямо из браузера.

### Основные эндпоинты

| Метод | Путь                | Описание                        |
|-------|---------------------|---------------------------------|
| GET   | `/api/notes`        | Получить все заметки (с фильтром и сортировкой) |
| GET   | `/api/notes/:id`    | Получить заметку по ID          |
| POST  | `/api/notes`        | Создать новую заметку           |
| PUT   | `/api/notes/:id`    | Обновить заметку                |
| DELETE| `/api/notes/:id`    | Удалить заметку                 |
| GET   | `/api/categories`   | Получить все категории (`?include_deleted=1` и `?updated_after=<мс>` добавляют удалённые) |
| POST  | `/api/categories`   | Создать категорию               |
| PUT   | `/api/categories/:id`| Обновить категорию (возвращает удалённую) |
| DELETE| `/api/categories/:id`| Удалить категорию (остаётся как «надгробие» 30 дней) |
| GET   | `/api/settings`     | Получить настройки               |
| PUT   | `/api/settings`     | Обновить настройки               |

- `sqlite3` – база данных

## 📝 Примечания

- База данных создаётся автоматически при первом запуске сервера (файл `notepad.db` в папке `backend`).
- Для импорта существующего JSON-бэкапа используйте:
  ```bash
  cd backend
  node scripts/importFromJson.js
  ```
  (путь к файлу прописан в скрипте, можно изменить).
- При изменении схемы БД удалите `notepad.db` – сервер пересоздаст таблицы.
